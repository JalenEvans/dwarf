# @dwarf/compiler

Native Node.js addon for the Dwarf compiler. Compiles Dwarf source code to TypeScript (and other targets).

## Features

- **Native performance** — compiled via napi-rs for maximum speed
- **Automatic WASM fallback** — falls back to `@dwarf/compiler-wasm` when native binary is unavailable
- **Same API** as the WASM package

## Installation

```bash
npm install @dwarf/compiler
```

## Usage

```js
const { compile, compileSimple, version } = require('@dwarf/compiler');

const result = compile('fn main() = "Hello, World!"', 'hello.kzd');
console.log(result.output);
// // Generated by Dwarf v0.1.0
// export async function main(): string {
//   return "Hello, World!";
// }

// With options
const result2 = compile('fn main() = 42', 'main.dwarf', { target: 'ts', pretty: true });

// Simplified
const result3 = compileSimple('fn main() = true', 'test.dwarf');
```

## API

### `compile(source, filename, options?)`

- `source` — Dwarf source code (string)
- `filename` — Source filename for error reporting (string)
- `options` — Compile options object or JSON string `{ target?, pretty?, skip_passes? }`

Returns `{ success, output, diagnostics, outputExtension }`.

### `compileSimple(source, filename)`

Simplified version with TypeScript target defaults.

### `version()`

Returns the compiler version string.
