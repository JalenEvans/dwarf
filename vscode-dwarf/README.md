# Dwarf Language Support for VS Code

Syntax highlighting and snippets for Dwarf (.kzd) files.

## Features

- Syntax highlighting for `.kzd` files
- Code snippets for common patterns (functions, types, tests, etc.)
- Language configuration (bracket matching, auto-closing pairs)

## Usage

Install the extension and open any `.kzd` file. Syntax highlighting activates automatically.

## Snippets

| Prefix | Description |
|--------|-------------|
| `fn` | Function declaration |
| `pfn` | Pure function declaration |
| `let` | Let binding |
| `if` | If expression |
| `match` | Match expression |
| `@test` | Test function |
| `record` | Record type |
| `import` | Module import |
